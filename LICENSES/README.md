# Open-source license index

This standalone project retains upstream source, modification notes, and license text beside each port:

- OpenKarto / slam_toolbox core: `third_party/slam_toolbox_core/`
  - `LICENSE-KARTO`
  - `LICENSE-SLAM-TOOLBOX`
  - `UPSTREAM.md`
  - `MODIFICATIONS.md`
- Nav2 DWB-derived local planner port: `planning/dwb_local_planner_dora_node/`

Boost.Graph, Ceres Solver, Eigen, yaml-cpp, and Dora remain system or separately installed dependencies and retain their upstream licenses. No ROS runtime is included or required.
